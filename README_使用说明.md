# ⚡ JobCruise 求职自动化巡航助手使用说明

> **现代智能求职与流水线巡航助手**：全新升级 **全网流水线自动化巡航 (BOSS直聘 ➔ 猎聘 ➔ 拉勾)**、**每日复盘与战略顾问**、**五维未回复归因**、**职业词条高亮选择库**、**全功能控制后台** 与 **网申档案自主配置**。

---

## 🌟 核心功能一览

### 1. 🌐 一键开启今日全网流水线巡航
- 在右上角插件弹窗中，点击 **「🚀 一键开启今日全网巡航」**；
- 插件会自动打开 **BOSS直聘** 开始筛选并投递高亮匹配岗位；
- 达到设定目标（例如 10 个）后，自动关闭并平滑切换到 **猎聘网** 继续巡航；
- 猎聘网达标后，自动切换到 **拉勾招聘** 进行收尾；
- 全程自动控制 9~15 秒真实拟人延迟，全量过滤黑名单和低于 9K 薪资岗位，随时可点击停止。

### 2. 🧠 每日投递复盘与战略顾问
- 投递完一天后，在插件中点击 **「🧠 每日投递复盘与战略顾问」**：
  - **五维未回复归因**：时效黄金窗口分析、平台生态时延差、隐形门槛排查、自荐钩子锐度、虚挂假 HC 侦测；
  - **四大赛道行业前沿雷达**：电商/达人、游戏/社区、商业摄影/数码影像、音频/音乐赛道招聘趋势与前沿技能；
  - **大厂破局战术**：大疆、影石、腾讯、字节、网易、米哈游针对性打法；
  - **简历与作品集扩充清单**：多维度案例扩充建议与筛选条件自进化；
  - **一键战报导出**：支持导出 Markdown 复盘文件。

### 3. 🏷️ 职业词条高亮选择库（选中的高亮词条才投递）
- 在后台可视化点选职业标签，**点亮即生效**（如 `达人运营`, `千川投放`, `商业摄影`, `游戏社区`, `音频`）；未选中的置灰不投；
- 岗位标题包含当前高亮词条时才投递，杜绝误投无关岗位；
- 支持自由添加自定义词条。

### 4. 👤 个人网申资料与档案配置
- 在后台「⚙️ 全局参数与安全设置」中，可自由填写个人姓名、手机、微信、邮箱、学校、学历、期望城市与作品集链接；
- 所有资料仅保存在用户浏览器本地，完全自主可调，用于大厂 ATS 智能回填。

### 5. 📊 每日投递记录表格（支持一键导出 Excel / CSV）
- 结构化清晰记录每一笔投递实绩（时间、平台、企业、岗位、薪资、命中词条、文案、状态）；
- 支持按企业/岗位关键字实时搜索，按平台过滤；
- 点击「📥 导出 Excel (CSV)」生成 UTF-8 BOM 报表。

---

## 🚀 极速安装与更新方法

1. 打开浏览器扩展管理页面：
   - **Edge 浏览器**：地址栏输入 `edge://extensions/`
   - **Chrome 浏览器**：地址栏输入 `chrome://extensions/`
2. 确保右上角的 **「开发者模式」** 已开启；
3. 点击左上角 **「加载解压缩的扩展」**，选中本插件文件夹；
4. 点击右上角扩展栏图钉📌固定插件即可开始使用！
