# ⚡ JobCruise 求职自动化巡航助手 (Open-Source Job Autopilot)

> **专为现代求职者打造的开源求职自动化巡航与战略辅助系统**  
> 全面支持 **多平台全自动流水线接力巡航 (BOSS直聘 ➔ 猎聘网 ➔ 拉勾招聘)**、**职业高亮词条库**、**每日投递复盘与战略顾问**、**五维未回复归因诊断**、**行业前沿雷达**、**大厂破局战术** 与 **个人资料自主配置**。

---

## 🌟 核心功能全景

### 1. 🌐 一键开启今日全网流水线巡航
- **多平台自动交接**：点击「🚀 一键开启今日全网巡航」，自动化引擎按序接力巡航第三方优质招聘平台：
  `BOSS直聘` → `猎聘网` → `拉勾招聘`。
- **目标配额与平滑交接**：可自选每站目标（5 / 10 / 15 / 20 个/站），当前平台达标或无合适岗位后，自动关闭当前标签页并无缝拉起下一平台。
- **全链路进度可视化**：在右上角 Popup、全功能后台 Dashboard 及页面左侧悬浮 HUD 同步呈现流水线进度百分比与完成度，随时可一键安全终止。

### 2. 🧠 每日投递复盘与战略顾问 (AI Career Consultant)
- **五维未回复归因诊断**：
  - ⏱️ **时效与黄金窗口期**：诊断投递时间分布，评估工作日 09:30-11:30 / 14:00-16:30 黄金时段占比；
  - 🌐 **平台生态时延差**：对比分析 BOSS 即时聊天、猎聘中高端猎头中转与拉勾互联网招聘的响应周期；
  - 🔍 **隐形门槛与年限倒挂**：智能探测招聘 JD 中是否存在隐藏学历/年限偏好；
  - 🎯 **自荐话术钩子锐度**：评估首句钩子是否精准直击 JD 痛点；
  - 👻 **虚挂假 HC 侦测**：自动警示长时间未更新、仅用于收集简历的非活跃岗位。
- **四大赛道行业前沿雷达**：
  - 实时聚合 **电商/达人运营**、**游戏/社区运营**、**数码影像/视觉策划**、**音乐/音频运营** 的招聘动向、JD 高频技能与前沿资讯。
- **大厂破局战术方案**：
  - 针对 **大疆 (DJI)**、**影石 (Insta360)**、**腾讯 (IEG/TME)**、**字节跳动 (抖音电商)**、**网易游戏**、**米哈游** 提供 1 对 1 击穿破局思路与加分项。
- **简历与作品集动态进化清单**：
  - 输出简历精修要点与作品集建议扩充的案例清单。
- **一键战报导出**：支持一键导出 Markdown 今日求职复盘分析战报。

### 3. 🏷️ 职业词条高亮选择库（69 个高频词条）
- **点亮即生效**：标签发光高亮（如 `达人运营`, `千川投放`, `商业摄影`, `游戏社区`, `音频`）即代表纳入投递范围；未选中的置灰不投；
- **精准匹配**：岗位标题必须命中至少一个高亮词条才投递，杜绝误投无关岗位；
- **支持自由增删**：支持自定义添加岗位词条并实时持久化保存。

### 4. 💬 自定义打招呼与自荐话术
- 弱化生硬与夸大业绩，突出核心业务匹配度、执行力与实际落地成果，结尾带有健康祝福与礼貌问候；
- 支持后台可视化自由修改，支持 `{jobTitle}`, `{company}`, `{matchedTag}`, `{portfolioUrl}` 动态占位符。

### 5. 👤 个人网申资料完全自主可控 (ATS 智能回填)
- 在控制后台自由配置：姓名、性别、手机、微信号、邮箱、毕业院校、学历、专业、毕业年份、期望城市、作品集主页与简历链接；
- 支持大厂官网及北森/大易等网申系统一键辅助填表。

### 6. 📊 每日投递记录表格（支持一键导出 Excel / CSV）
- 结构化清晰记录每一笔投递实绩（投递时间、目标平台、企业名称、岗位名称、薪资待遇、命中的高亮词条、投递状态、沟通文案）；
- 支持多维关键字筛选与平台过滤，带 UTF-8 BOM 专业 Excel 导出。

## 🚀 30 秒极速安装与使用说明

1. 打开 Chrome 或 Edge 浏览器扩展管理页面：
   - **Chrome**: `chrome://extensions/`
   - **Edge**: `edge://extensions/`
2. 开启右上角的 **「开发者模式」** (Developer mode) 开关；
3. 点击 **「加载已解压的扩展程序」** (Load unpacked)；
4. 选择插件所在根目录；
5. 点击浏览器右上角拼图图标，将 **「JobCruise 求职巡航」** 固定到工具栏；
6. 点击插件图标，进入 **「⚙️ 完整后台」** 配置个人资料与词条，点击 **「🚀 一键开启今日全网巡航」** 即可开启极速求职！

## ⚙️ 核心配置参数推荐

| 参数项 | 默认值 | 推荐理由 |
| :--- | :--- | :--- |
| **单站巡航目标** | 10 个 | 保证质量与安全，三站合计 30 个 |
| **每日投递上限** | 30 个 | 严格符合各招聘平台反爬与风控阈值 |
| **拟人化间隔** | 9 ~ 15 秒 | 模拟人类正常浏览、阅读岗位及打招呼节奏 |
| **最低月薪门槛** | 9 K | 自动过滤 9K 以下低含金量或外包岗位 |
| **企业黑名单** | 劳务外包, 催收, 电话销售... | 自动跳过涉嫌虚假或不匹配企业 |

## 🔒 隐私与安全性保障
- **零数据上报**：所有投递日志、个人资料与高亮词条配置均纯本地存储于 `chrome.storage.local`；
- **完全开源可审**：不包含任何第三方追踪、外发接口或未授权代码。
